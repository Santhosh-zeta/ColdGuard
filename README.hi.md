# 🧊 कोल्डगार्ड (ColdGuard)

**ColdGuard** तापमान लॉग देखकर वैक्सीन की बची हुई शक्ति का अनुमान लगाता है। यह स्वास्थ्यकर्मियों को बताता है कि वैक्सीन **उपयोग करें**, **जांच करें**, या **नष्ट करें**। यह फैसला लेने में मदद करता है; ज़रूरत पड़ने पर स्वास्थ्य अधिकारी से सलाह लें।

## वेब ऐप चलाएँ

टर्मिनल में ये कमांड चलाएँ:

```bash
git clone https://github.com/Santhosh-zeta/ColdGuard.git
cd ColdGuard
pip install -r requirements.txt
PYTHONPATH=. streamlit run web_app/app.py
```

ऐप खुलने के लिए टर्मिनल में दिखाए गए लोकल URL को ब्राउज़र में खोलें।

## मोबाइल ऐप चलाएँ

यह मोबाइल ऐप Android पर Expo Go के साथ चल सकता है।

1. अपने Android फ़ोन पर Play Store से **Expo Go** इंस्टॉल करें।
2. कंप्यूटर पर ColdGuard की `mobile_app` फ़ोल्डर में जाएँ और निर्भरताएँ इंस्टॉल करके ऐप शुरू करें:

   ```bash
   cd mobile_app
   npm install
   npx expo start
   ```

3. टर्मिनल में दिखे QR कोड को Expo Go से स्कैन करें। फ़ोन और कंप्यूटर एक ही Wi-Fi नेटवर्क पर होने चाहिए।

## नतीजे कैसे पढ़ें

ColdGuard वैक्सीन की न्यूनतम ज़रूरी शक्ति से ऊपर रहने की संभावना के आधार पर नतीजा देता है:

- **उपयोग करें (USE)** — संभावना 90% से ज़्यादा है। वैक्सीन की शक्ति पर्याप्त है।
- **जांच करें (INVESTIGATE)** — संभावना 70% से ज़्यादा, लेकिन 90% या उससे कम है। उपयोग से पहले आगे की जांच करें।
- **नष्ट करें (DISCARD)** — संभावना 70% या उससे कम है। वैक्सीन का उपयोग न करें।

वैक्सीन का प्रकार और तापमान लॉग सही से दर्ज करें। रिपोर्ट में अनुमानित शक्ति और 90% विश्वास अंतराल भी देखें।
